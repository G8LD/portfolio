# Steven Yang — Portfolio

Personal developer portfolio built with React, TypeScript, Vite, Tailwind CSS v4, and shadcn/ui.

## Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4 + shadcn/ui
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Hosting:** Cloudflare Pages (Frontend only)

## Project Structure

- `src/data/portfolioData.ts`: Central source of truth for all portfolio content (bio, experiences, projects, skills, education).
- `src/components/`: Reusable UI sections and shadcn primitives.
- `public/games/copi/`: Playable Godot web game export.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production (outputs to dist/)
npm run build
```
